# 1.1 plan 1: the level 2 charge shot — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A kid can set their hero's Charge shot to Off, On or Level 2. At Level 2, holding shoot for 2 seconds makes the hero blink faster, and letting go fires a bigger, stronger shot with its own picture.

**Architecture:**
- **Abilities:** the hero's abilities gain `chargeLevel2: boolean`, which needs `chargeShot`. The editor shows the two as one three-step control.
- **Look:** the hero's look gains a fixed 16×12 `chargedShot2` animation with no hitbox.
- **Format 6:** it adds both. Older heroes get a centred copy of their Charged shot.
- **The game:** it fires level 2 when the setting is on and the charge has reached 120 steps. The renderer blinks twice as fast at that point and draws the new picture.

**Tech Stack:** Next.js 16, React 19, TypeScript (strict), Zod 4, Vitest 4 (jsdom), Testing Library, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-12-1.1-gameplay-tweaks-design.md` (section 2)

## Global Constraints

- **Level 1, unchanged:** 60 steps of holding, 12×10, 3 damage, carries on through what it destroys.
- **Level 2:** 120 steps of holding, 16×12, 5 damage, carries on through what it destroys like level 1, the same speed, centred on the pose's shot line.
- **Releasing:** before 60 steps fires nothing; from 60 to 119 fires level 1; at 120 or more fires level 2, and only when level 2 is on.
- **Blink:** the white blink changes every 4 steps from level 1, and every 2 steps once level 2 is reached.
- **The editor's control:** the "Charge shot" step control reads **Off / On / Level 2**. Choosing Off turns level 2 off too, and each choice is one undo step.
- **The picture's name:** "Level 2 shot", fixed at 16×12. Its note while level 2 is off is "(needs level 2)".
- **Messages:**
  - the damaged-file message is "The hero's level 2 charge shot needs its charge shot on.";
  - the command's refusal is "A level 2 charge shot needs the charge shot on."
- **Format 6.** Format 5 and older games open with level 2 off and play exactly as before.
- Never commit `test-art/`: stage with `git add -A src tests e2e docs`.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Every task ends with the whole unit suite green (`npx vitest run`).

## Review Focus

2. **The assistant turns charge shot off on a hero with level 2 on:** level 2 goes off too, so the game stays valid (Task 2 test).

```ts
// Pads a picture evenly on every side to a bigger size (the odd pixel on the right and bottom).
export function centreRows(rows: string[], w: number, h: number): string[] {
  const left = Math.floor((w - rows[0].length) / 2);
  const top = Math.floor((h - rows.length) / 2);
  const blank = ".".repeat(w);
  const padded = rows.map((row) => ".".repeat(left) + row + ".".repeat(w - row.length - left));
  return [...Array.from({ length: top }, () => blank), ...padded, ...Array.from({ length: h - rows.length - top }, () => blank)];
}

// Format 6 gave the hero a Level 2 shot. A hero without one starts with its own Charged shot,
// centred on the bigger canvas, so it keeps the kid's colours.
export function withLevel2Shot(look: Look): Look {
  if (look.animations.chargedShot2 || !look.animations.chargedShot) return look;
  const charged = look.animations.chargedShot;
  return {
    ...look,
    animations: {
      ...look.animations,
      chargedShot2: { frames: charged.frames.map((rows) => centreRows(rows, 16, 12)), speed: charged.speed, size: { w: 16, h: 12 } },
    },
  };
}
```

```ts
function upgradeHero5(hero: unknown): unknown {
  if (!isObject(hero)) return hero;
  const abilities = isObject(hero.abilities) ? { chargeLevel2: false, ...hero.abilities } : hero.abilities;
  if (!isObject(hero.look) || !isObject(hero.look.animations)) return { ...hero, abilities };
  try {
    return { ...hero, abilities, look: withLevel2Shot(hero.look as unknown as Look) };
  } catch {
    return { ...hero, abilities }; // a damaged look: the schema refuses it
  }
}
```
