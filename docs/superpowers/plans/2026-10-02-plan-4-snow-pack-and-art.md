# Snow Pack and Pixel Art Implementation Plan (Milestone 1, Plan 4 of 7)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the coloured rectangles with original pixel art: a snow content pack with tiles for two looks (outdoor and cave), an animated hero, sprites for every enemy, pickup, platform and shot, and the Blizzard Bot boss.

**Architecture:** Art is data. Each sprite is a list of text rows, one character per pixel, coloured through one shared palette; `.` is transparent. Tiles are generated by small functions; characters are drawn by hand. At run time a sprite cache paints each sprite onto a small offscreen canvas the first time it is needed (once per facing direction), and the renderer draws those with `drawImage`. Anything without art still draws as its coloured rectangle, so the renderer never shows a blank.

**Tech Stack:** TypeScript (strict), Vitest, 2D canvas. No image files, no new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-02-playable-core-ai-level-builder-design.md` (section 3 "Snow pack contents")

**Plan series for milestone 1** (the snow pack, the level pieces and the checker were too much for one plan, so there are now seven):

1. Project model and commands (done)
2. Runtime core (done)
3. Runtime things (done)
4. Snow pack and pixel art (this plan)
5. Level pieces and the checker
6. Editor UI and IndexedDB storage
7. AI assistant

## Global Constraints

- All art is original. No Capcom characters, colours schemes copied from their games, or sprite shapes traced from them. The hero is a teal-helmeted robot kid of our own.
- Sprites are drawn facing right; the renderer mirrors them for facing left.
- Tile sprites are exactly 16 by 16. Player sprites are exactly 16 by 24.
- A sprite is drawn with its bottom centre on the bottom centre of the thing's box.
- `src/runtime/sim/` stays free of rendering code; art lives in `src/content/` and `src/runtime/render/`.
- Import alias `@/` maps to `src/`.

## Decisions this plan makes

- **Art as text, not PNG files.** The spec said "PNG sheets in `public/packs/snow/`". Text pixel maps are reviewable in a diff, need no image loading, can be checked by tests (every row the right width, every colour in the palette), and can later be edited by the editor or the AI. Task 2 updates the spec.
- **The demo pack becomes the snow pack.** Tile ids stay the same (1 ground, 2 ice, 3 ladder, 4 spike, 5 ledge), as do the ten thing types.
- **Ground tiles auto-cap.** A ground tile with something other than ground above it draws its "top" sprite (snow-capped outdoors, frosted in the cave); ground under ground draws the plain fill.
- **One extra field in the simulation.** `Player.shotTimer` counts down for 12 steps after a shot so the hero can be drawn in a shooting pose. This is the only sim change.

## Review Focus

1. **Something with no art** (a tile id or thing type the art set does not cover): drawn as its coloured rectangle, never blank and never a crash. Tested in Task 5.
2. **A typo in a sprite** (a short row, a colour letter not in the palette): caught by a test, not shown as a glitch in the game. Tested in Tasks 1 and 3.
3. **Facing left**: draws a mirrored sprite, not the right-facing one. Tested in Tasks 4 and 5.
4. **Drawing cost**: each sprite is painted once per direction and cached, not repainted every frame. Tested in Task 4.
5. **Ground at the top edge of a zone** (row 0, with nothing above): uses the capped "top" sprite. Tested in Task 5.

```ts
import type { ContentPack } from "@/model/contentPack";
import { TILE_SIZE } from "@/model/geometry";

// One character per pixel; "." is transparent and every other character is a palette key.
export type Sprite = { w: number; h: number; rows: string[] };

export function sprite(rows: string[]): Sprite {
  return { w: rows[0]?.length ?? 0, h: rows.length, rows };
}

// A ground tile can have a "top" sprite, used when the tile above is something else.
export type TileArt = { fill: Sprite; top?: Sprite };

export const PLAYER_POSES = [
  "stand",
  "standShoot",
  "run1",
  "run2",
  "jump",
  "jumpShoot",
  "climb",
  "hurt",
] as const;
export type PlayerPose = (typeof PLAYER_POSES)[number];

export type ArtSet = {
  palette: Record<string, string>;
  backgrounds: Record<string, string>; // by variant
  tiles: Record<string, Record<number, TileArt>>; // by variant, then tile id
  player: Record<PlayerPose, Sprite>;
  things: Record<string, Sprite[]>; // by thing type: one or more frames
  playerShot: Sprite;
  enemyShot: Sprite;
};

export function spriteProblems(
  name: string,
  s: Sprite,
  palette: Record<string, string>,
): string[] {
  if (s.rows.length === 0) return [`${name} has no rows.`];
  const problems: string[] = [];
  s.rows.forEach((row, y) => {
    if (row.length !== s.w) problems.push(`${name} row ${y} is ${row.length} wide, not ${s.w}.`);
    const unknown = [...row].find((ch) => ch !== "." && !(ch in palette));
    if (unknown) problems.push(`${name} row ${y} uses "${unknown}", which is not in the palette.`);
  });
  return problems;
}

// Everything wrong with an art set for a pack: missing art, wrong sizes, broken sprites.
export function artProblems(art: ArtSet, pack: ContentPack): string[] {
  const problems: string[] = [];
  const check = (name: string, s: Sprite, w?: number, h?: number) => {
    problems.push(...spriteProblems(name, s, art.palette));
    if (w !== undefined && (s.w !== w || s.h !== h)) {
      problems.push(`${name} is ${s.w} by ${s.h}, not ${w} by ${h}.`);
    }
  };

  for (const variant of pack.variants) {
    if (!art.backgrounds[variant]) problems.push(`No background colour for variant "${variant}".`);
    for (const tile of pack.tiles) {
      const tileArt = art.tiles[variant]?.[tile.id];
      if (!tileArt) {
        problems.push(`No art for tile "${tile.name}" in variant "${variant}".`);
        continue;
      }
      check(`Tile "${tile.name}" (${variant})`, tileArt.fill, TILE_SIZE, TILE_SIZE);
      if (tileArt.top) check(`Tile "${tile.name}" top (${variant})`, tileArt.top, TILE_SIZE, TILE_SIZE);
    }
  }
  for (const pose of PLAYER_POSES) check(`Player ${pose}`, art.player[pose], 16, 24);
  for (const def of pack.things) {
    const frames = art.things[def.type];
    if (!frames || frames.length === 0) {
      problems.push(`No art for thing "${def.type}".`);
      continue;
    }
    frames.forEach((s, i) => check(`Thing "${def.type}" frame ${i}`, s));
  }
  check("Player shot", art.playerShot);
  check("Enemy shot", art.enemyShot);
  return problems;
}
```

// ---- Tiles, generated ----

type Grid = string[][];
const grid = (w: number, h: number, fill: string): Grid =>
  Array.from({ length: h }, () => new Array<string>(w).fill(fill));
const toSprite = (g: Grid): Sprite => sprite(g.map((row) => row.join("")));
const copy = (g: Grid): Grid => g.map((row) => [...row]);

function speckled(base: string, dark: string): Grid {
  const g = grid(16, 16, base);
  for (let y = 0; y < 16; y++) {
    for (let x = 0; x < 16; x++) if ((x * 7 + y * 13) % 23 === 0) g[y][x] = dark;
  }
  return g;
}

function snowCapped(below: Grid): Grid {
  const g = copy(below);
  for (let x = 0; x < 16; x++) {
    g[0][x] = "n";
    g[1][x] = "n";
    g[2][x] = x % 3 === 0 ? "N" : "n";
    if (x % 5 === 1) g[3][x] = "N";
  }
  return g;
}

function bricks(): Grid {
  const g = grid(16, 16, "c");
  for (let x = 0; x < 16; x++) {
    g[7][x] = "C";
    g[15][x] = "C";
  }
  for (let y = 0; y < 7; y++) g[y][3] = "C";
  for (let y = 8; y < 15; y++) g[y][11] = "C";
  return g;
}

function frosted(below: Grid): Grid {
  const g = copy(below);
  for (let x = 0; x < 16; x++) {
    g[0][x] = "N";
    if (x % 4 === 0) g[1][x] = "N";
  }
  return g;
}

function ice(): Grid {
  const g = grid(16, 16, "I");
  for (let y = 0; y < 16; y++) {
    for (let x = 0; x < 16; x++) {
      if (y === 0) g[y][x] = "i";
      else if (y === 15) g[y][x] = "B";
      else if ((x + y) % 6 === 0 && y < 12) g[y][x] = "i";
    }
  }
  return g;
}

function ladder(): Grid {
  const g = grid(16, 16, ".");
  for (let y = 0; y < 16; y++) {
    g[y][2] = "h";
    g[y][3] = "H";
    g[y][12] = "h";
    g[y][13] = "H";

  for (const y of [3, 11]) {
    for (let x = 4; x < 12; x++) {
      g[y][x] = "h";
      g[y + 1][x] = "H";
    }
  }
  return g;
}

function spikes(): Grid {
  const g = grid(16, 16, ".");
  for (let j = 0; j < 4; j++) {
    const x0 = j * 4;
    for (let y = 4; y < 16; y++) {
      g[y][x0 + 1] = "w";
      g[y][x0 + 2] = "g";
    }
    for (let y = 10; y < 16; y++) {
      g[y][x0] = "g";
      g[y][x0 + 3] = "G";
    }
  }
  for (let x = 0; x < 16; x++) g[15][x] = "G";
  return g;
}

function ledge(): Grid {
  const g = grid(16, 16, ".");
  for (let x = 0; x < 16; x++) {
    g[0][x] = "n";
    g[1][x] = "N";
    g[2][x] = "h";
    g[3][x] = "H";

  for (let y = 0; y < 8; y++) {
    g[y][0] = "k";

```ts
export function playerPose(p: Player, steps: number): { pose: PlayerPose; flip: boolean } {
  const flip = p.facing < 0;
  if (p.hurt > 0) return { pose: "hurt", flip };
  if (p.onLadder) return { pose: "climb", flip: Math.floor(p.y / 8) % 2 === 1 };
  const shooting = p.shotTimer > 0;
  if (!p.onGround) return { pose: shooting ? "jumpShoot" : "jump", flip };
  if (p.vx !== 0) return { pose: Math.floor(steps / 6) % 2 === 0 ? "run1" : "run2", flip };
  return { pose: shooting ? "standShoot" : "stand", flip };
}

export function thingFrame(e: Entity, steps: number, count: number): number {
  const pick = (frame: number) => Math.min(frame, count - 1);
  switch (e.behaviour) {
    case "shielded":
      return pick(e.mode === "open" ? 1 : 0);
    case "dropper":
      return pick(e.mode === "hang" ? 0 : 1);
    case "jumper":
      return pick(e.onGround ? 0 : 1);
    case "boss":
      return pick(e.mode === "jump" ? 1 : e.mode === "shot" ? 2 : 0);
    default:
      return Math.floor(steps / 8) % count;
  }
}

  make: MakeCanvas,
): (s: Sprite, flip: boolean) => CanvasImageSource {
  const painted = new WeakMap<Sprite, { normal?: CanvasImageSource; flipped?: CanvasImageSource }>();
  return (s, flip) => {
    let entry = painted.get(s);
    if (!entry) {
      entry = {};
      painted.set(s, entry);
    }
    const key = flip ? "flipped" : "normal";
    const found = entry[key];
    if (found) return found;
    const { canvas, ctx } = make(s.w, s.h);
    for (let y = 0; y < s.h; y++) {
      for (let x = 0; x < s.w; x++) {
        const colour = palette[s.rows[y][flip ? s.w - 1 - x : x]];
        if (!colour) continue; // "." and anything unknown stay transparent
        ctx.fillStyle = colour;
        ctx.fillRect(x, y, 1, 1);
      }
    }
    entry[key] = canvas;
    return canvas;
  };
}

export const browserCanvas: MakeCanvas = (w, h) => {
  const canvas = document.createElement("canvas");
  canvas.width = w;
  canvas.height = h;
  const ctx = canvas.getContext("2d");
  if (!ctx) throw new Error("This browser cannot draw on a canvas.");
  return { canvas, ctx };
};
```

import type { ContentPack, ThingBehaviour, TileBehaviour } from "@/model/contentPack";
import { TILE_SIZE, tileIndex, zoneSize } from "@/model/geometry";
import type { Zone } from "@/model/schema";
import { ENEMY_SHOT_SIZE, SCREEN_H, SCREEN_W, SHOT_H, SHOT_W } from "@/runtime/sim/constants";
import { num, type Box, type Entity } from "@/runtime/sim/entities/types";
import type { Camera, Sim } from "@/runtime/sim/state";
import { firstTile, lastTile } from "@/runtime/sim/tilemap";
import { viewFor } from "@/runtime/sim/view";
import { playerPose, thingFrame, type ArtSet, type Sprite } from "./art";

export type Ctx2D = Pick<
  CanvasRenderingContext2D,
  "fillStyle" | "fillRect" | "font" | "textAlign" | "fillText" | "drawImage"
>;

// Sprite art, and a way to turn a sprite into something drawImage can draw.
export type Skin = { set: ArtSet; image: (s: Sprite, flip: boolean) => CanvasImageSource };

// Colours for anything drawn without art.
export const BACKGROUNDS: Record<string, string> = { outdoor: "#9bd4ff", cave: "#1c2740" };
export const PLAYER_COLOUR = "#2f6bff";
export const SHOT_COLOUR = "#fff275";
export const ENEMY_SHOT_COLOUR = "#f72585";
export const BOSS_BAR_COLOUR = "#ff9e9e";
export const ENTITY_COLOURS: Record<ThingBehaviour, string> = {
  walker: "#ff8c42",
  flyer: "#c77dff",
  turret: "#8d99ae",
  jumper: "#80ed99",
  shielded: "#ffd166",
  dropper: "#ef476f",
  platform: "#adb5bd",
  health: "#ff006e",
  boss: "#00b4d8",
};
const TILE_COLOURS: Record<TileBehaviour, string> = {
  solid: "#e8f4ff",
  ice: "#7fd6f5",
  ladder: "#c9853a",
  spike: "#ff4d6d",
  oneWay: "#a8b8c8",
};

function rect(ctx: Ctx2D, colour: string, x: number, y: number, w: number, h: number): void {
  ctx.fillStyle = colour;
  ctx.fillRect(x, y, w, h);
}

// Draws a sprite with its bottom centre on the bottom centre of a box.
function onBox(ctx: Ctx2D, skin: Skin, s: Sprite, flip: boolean, box: Box, ox: number, oy: number) {
  const x = Math.round(box.x + box.w / 2 - s.w / 2) + ox;
  const y = Math.round(box.y + box.h - s.h) + oy;
  ctx.drawImage(skin.image(s, flip), x, y);
}

// A vertical bar of one-pixel ticks, filled from the bottom.
function healthBar(ctx: Ctx2D, x: number, value: number, max: number, colour: string): void {
  rect(ctx, "#000000", x - 1, 15, 8, max * 2 + 1);
  for (let i = 0; i < value; i++) rect(ctx, colour, x, 14 + (max - i) * 2, 6, 1);
}

function drawZone(
  ctx: Ctx2D,
  zone: Zone,
  pack: ContentPack,
  camera: Camera,
  dx: number,
  dy: number,
  skin: Skin | undefined,
): void {
  const size = zoneSize(zone.scroll, zone.screens);
  const behaviours = new Map(pack.tiles.map((t) => [t.id, t.behaviour]));
  const tileArt = skin?.set.tiles[zone.variant];
  const camX = Math.round(camera.x);
  const camY = Math.round(camera.y);
  const background = skin?.set.backgrounds[zone.variant] ?? BACKGROUNDS[zone.variant] ?? "#404040";
  rect(ctx, background, dx, dy, SCREEN_W, SCREEN_H);

  const x0 = Math.max(0, firstTile(camX));
  const x1 = Math.min(size.width - 1, lastTile(camX + SCREEN_W));
  const y0 = Math.max(0, firstTile(camY));
  const y1 = Math.min(size.height - 1, lastTile(camY + SCREEN_H));
  for (let ty = y0; ty <= y1; ty++) {
    for (let tx = x0; tx <= x1; tx++) {
      const id = zone.tiles[tileIndex(size, tx, ty)];
      const behaviour = behaviours.get(id);
      if (!behaviour) continue;
      const px = tx * TILE_SIZE - camX + dx;
      const py = ty * TILE_SIZE - camY + dy;
      const art = tileArt?.[id];
      if (skin && art) {
        const above = ty > 0 ? zone.tiles[tileIndex(size, tx, ty - 1)] : -1;
        ctx.drawImage(skin.image(above !== id && art.top ? art.top : art.fill, false), px, py);
      } else {
        rect(ctx, TILE_COLOURS[behaviour], px, py, TILE_SIZE, behaviour === "oneWay" ? 4 : TILE_SIZE);
      }
    }
  }
}

function drawEntity(ctx: Ctx2D, sim: Sim, e: Entity, skin: Skin | undefined, ox: number, oy: number) {
  const flashing = e.flash > 0 && e.flash % 4 < 2;
  const frames = skin?.set.things[e.type];
  if (skin && frames && frames.length > 0) {
    if (flashing) return; // blink
    const frame = frames[thingFrame(e, sim.steps, frames.length)];
    onBox(ctx, skin, frame, e.facing < 0, e, ox, oy);
    return;
  }
  rect(
    ctx,
    flashing ? "#ffffff" : ENTITY_COLOURS[e.behaviour],
    Math.round(e.x) + ox,
    Math.round(e.y) + oy,
    e.w,
    e.h,
  );
}

export function draw(ctx: Ctx2D, sim: Sim, skin?: Skin): void {
  const view = viewFor(sim);
  rect(ctx, "#000000", 0, 0, SCREEN_W, SCREEN_H);
  if (view.outgoing) {
    const { zoneIndex, camera, dx, dy } = view.outgoing;
    drawZone(ctx, sim.level.zones[zoneIndex], sim.pack, camera, Math.round(dx), Math.round(dy), skin);
  }
  const offsetX = Math.round(view.incoming.dx);
  const offsetY = Math.round(view.incoming.dy);
  drawZone(ctx, sim.map.zone, sim.pack, view.camera, offsetX, offsetY, skin);

  const originX = offsetX - Math.round(view.camera.x);
  const originY = offsetY - Math.round(view.camera.y);
  const p = sim.player;

  for (const slot of sim.slots) {
    if (slot.entity) drawEntity(ctx, sim, slot.entity, skin, originX, originY);
  }

  const blinkedOut = p.invuln > 0 && Math.floor(p.invuln / 4) % 2 === 1;
  if (sim.phase !== "dead" && !blinkedOut) {
    if (skin) {
      const { pose, flip } = playerPose(p, sim.steps);
      onBox(ctx, skin, skin.set.player[pose], flip, p, originX, originY);
    } else {
      const px = Math.round(p.x) + originX;
      const py = Math.round(p.y) + originY;
      rect(ctx, PLAYER_COLOUR, px, py, p.w, p.h);
      rect(ctx, "#ffffff", p.facing > 0 ? px + p.w - 4 : px + 1, py + 4, 3, 3);
    }
  }

  for (const shot of sim.shots) {
    const x = Math.round(shot.x) + originX;
    const y = Math.round(shot.y) + originY;
    if (skin) ctx.drawImage(skin.image(skin.set.playerShot, shot.vx < 0), x, y);
    else rect(ctx, SHOT_COLOUR, x, y, SHOT_W, SHOT_H);
  }
  for (const shot of sim.enemyShots) {
    const x = Math.round(shot.x) + originX;
    const y = Math.round(shot.y) + originY;
    if (skin) ctx.drawImage(skin.image(skin.set.enemyShot, shot.vx < 0), x, y);
    else rect(ctx, ENEMY_SHOT_COLOUR, x, y, ENEMY_SHOT_SIZE, ENEMY_SHOT_SIZE);
  }

  healthBar(ctx, 16, p.health, sim.settings.maxHealth, "#ffe08a");
  const boss = sim.slots.find((s) => s.entity?.behaviour === "boss")?.entity;
  if (boss) healthBar(ctx, 234, boss.health, num(boss.settings, "health", 28), BOSS_BAR_COLOUR);

  if (sim.phase === "won") {
    rect(ctx, "#000000", 0, 100, SCREEN_W, 40);
    ctx.fillStyle = "#ffffff";
    ctx.font = "16px monospace";
    ctx.textAlign = "center";
    ctx.fillText("STAGE CLEAR", SCREEN_W / 2, 126);
  }
}
