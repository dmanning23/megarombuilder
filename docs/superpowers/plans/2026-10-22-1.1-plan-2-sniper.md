# 1.1 plan 2: the Sniper — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A seventh enemy kind, "Sniper". It never walks and always faces the hero. Its shield blocks every shot from the front. Every 2 seconds it lowers the shield for 1 second and fires three level shots, 12 steps apart. Every enemy's Health choices gain 8 and 12.

**Architecture:**
- **One new behaviour, `sniper`:** added to every per-behaviour table (designs, look kinds, runtime sizes and health, the checker's weights, the pack, the editor and assistant names).
- **Two poses:** Guard (mode `"guard"`) and Shoot (mode `"shoot"`).
- **Runtime:** a small update function next to the Shield Guard's, plus one rule in the shield check.
- **Snow pack:** a drawn two-frame Sniper, which is both the pack enemy and the starting look for a kid's own.
- No file format change.

**Tech Stack:** Next.js 16, React 19, TypeScript (strict), Zod 4, Vitest 4 (jsdom), Testing Library, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-12-1.1-gameplay-tweaks-design.md` (section 3)

## Global Constraints

- **Names:**
  - the behaviour is `"sniper"`, shown as "Sniper";
  - the poses are `guard` "Guard" and `shoot` "Shoot";
  - the snow pack's enemy is type `"sniper"`, name "Sniper", description "Hides behind its shield, then fires three low shots.";
  - the assistant's words are "a sniper that hides behind its shield, then fires three low shots you jump over".
- **Timing (fixed, with no Shoots setting):**
  - it guards for 120 steps;
  - it is open for 60 steps;
  - it fires on open steps 1, 13 and 25 (12 apart), three shots in all.
- **Shots:** level (vy 0), from its shot point, at speed 2 (the `shotSpeed` setting, as for other shooters), doing its Damage.
- **Shield:** while guarding it blocks every player shot coming at the side it faces. Shots from behind, and all shots while it shoots, hurt it.
- **Health:**
  - `HEALTH_STEPS` becomes `[1, 2, 3, 5, 8, 12]` for every enemy;
  - a new Sniper starts at 8;
  - the pack Sniper has 8.
- **Settings:** a kid's Sniper uses Health and Damage only.
- **Snow Sniper:** a 14×16 body and shot point 9 (low enough to jump over).
- **Difficulty weight:** 2.5, harder than Shield Guard's 2.
- No game file format change.
- Never commit `test-art/`: stage with `git add -A src tests e2e docs`.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Every task ends with the whole unit suite green (`npx vitest run`).

## Review Focus

1. **A hero who jumps over the Sniper mid-burst:** the burst keeps firing the way it started, then the Sniper turns when it guards again (Task 2 test).
2. **A shot that reaches the Sniper's back** (for example one fired before it turned) hurts it while it guards (Task 2 test).
3. **Changing a Shield Guard to a Sniper and back** keeps the drawing, and both looks stay valid (Task 1 test).
4. **A kid's Sniper whose shot point is moved** fires from the new height. The pack Sniper fires from 9 (Task 2 test).
5. **An existing enemy with health 5:** the new steps don't change it, and 8 and 12 save and load (Task 1 test).

```ts
// The Sniper stands its ground behind its shield, turning to face the hero. Every 2 seconds it
// lowers the shield for a second and fires three level shots, 12 steps apart, the way it faced
// when it opened up.
export const SNIPER_GUARD_STEPS = 120;
export const SNIPER_OPEN_STEPS = 60;
export const SNIPER_SHOT_STEPS = [1, 13, 25];

const sniper: Update = (sim, e) => {
  fall(sim.map, e);
  e.timer++;
  if (e.mode !== "shoot") {
    e.facing = towardPlayer(sim, e);
    if (e.timer >= SNIPER_GUARD_STEPS) {
      e.mode = "shoot";
      e.timer = 0;
    }
    return;
  }
  if (SNIPER_SHOT_STEPS.includes(e.timer)) {
    fireAt(sim, e, e.facing * num(e.settings, "shotSpeed", 2), 0, num(e.settings, "shotDamage", 2));
  }
  if (e.timer >= SNIPER_OPEN_STEPS) {
    e.mode = "guard";
    e.timer = 0;
  }
};
```
